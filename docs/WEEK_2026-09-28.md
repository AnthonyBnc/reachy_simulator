## Wednesday 30/9 — `MujocoBackend` (≈ 3–4 h)

File: `reachy_sim/backends/mujoco_backend.py`. Reuse the code from `scripts/ex2_goto.py`.

```python
class MujocoBackend:
    def __init__(self, scene="reach_scene.xml", control_hz=20, settle_time=0.5): ...
    def reset(self, q_init=None) -> None: ...              # set qpos AND ctrl, settle 0.5 s
    def get_joint_positions(self) -> np.ndarray: ...       # (7,) rad, SDK order, by name
    def get_joint_velocities(self) -> np.ndarray: ...      # (7,) rad/s
    def get_ee_pose(self) -> np.ndarray: ...               # 4x4, r_arm_tip in torso frame
    def predict_ee(self, q) -> np.ndarray: ...             # hand position IF joints were at q (separate MjData)
    def send_joint_targets(self, q) -> None: ...           # write right-arm ctrl by name
    def set_goal_marker(self, pos_torso) -> None: ...      # mocap_pos (torso → world)
    def step(self) -> None: ...                            # mj_step x frame_skip (25 at 20 Hz)
    def render(self): ...                                  # "rgb_array"
    def close(self) -> None: ...
```

Key details:
- `frame_skip = round(1 / (control_hz * timestep))` = **25**.
- **Settle after reset:** run ~250 steps (0.5 s), because the tripod rises ~11 mm at startup ([SIMULATION_PHASE.md §0.1](SIMULATION_PHASE.md)).
- All name lookups happen once in `__init__`; never hard-code indices.

Tests `tests/test_mujoco_backend.py`:
- [ ] `reset(q)` then `get_joint_positions()` ≈ `q` (< 2°)
- [ ] `send_joint_targets(q)` + 20 × `step()` (1 s) → joints within 2° of `q`
- [ ] `get_ee_pose()` at zero joints ≈ `[0.030, -0.368, -0.638]` (< 5 mm), same as `compare_fk.py --sim-only`
- [ ] `predict_ee()` matches `get_ee_pose()` and doesn't change the simulation
- [ ] The torso doesn't move (< 1 mm) after settling

## Thursday 1/10 — Safety layer (≈ 3 h)

File: `reachy_sim/safety/shield.py`. **Pure numpy, no MuJoCo inside**, so the exact same code runs on the real robot in P3.

```python
class SafetyShield:
    def __init__(self, joint_limits, max_delta_deg=5.0, margin_deg=5.0, workspace_box=None): ...
    def filter(self, q_current, q_target, predict_ee=None) -> tuple[np.ndarray, dict]:
        """Return a safe target + info {"interventions": int, "reasons": [...]}."""
```

Rules, in order:
1. **Step limit:** `|q_target − q_current| ≤ max_delta_per_step` per joint
2. **Joint limits:** never move **further** outside (model range − margin). Home is at the edge for shoulder roll, so "must be inside" would force a jump.
3. **Workspace box:** if the predicted hand position is outside the box **and farther from it than now** → keep `q_current` (hold). Moves back toward the box are always allowed, because the home pose (hand at 0.03, −0.37, −0.64) starts outside it.
4. Count each rule that changed something

`configs/safety/default.yaml` (initial values, tune later):
```yaml
max_delta_per_step_deg: 5.0          # at 20 Hz = 100 deg/s max
joint_margin_deg: 5.0
workspace_box_m:                     # torso frame; goal region in front of the robot (covers GRASP_POSE, HANDOVER_POSE)
  x: [0.15, 0.65]
  y: [-0.60, 0.05]
  z: [-0.40, 0.25]
```

Tests `tests/test_safety_shield.py`:
- [ ] A small change passes unchanged, with 0 interventions
- [ ] A +30° request is cut to +5°
- [ ] A target beyond a joint limit is clipped to limit − margin
- [ ] Home at the limit edge doesn't force a jump
- [ ] A move that takes the hand further outside the box → hold `q_current`
- [ ] Starting from home (outside the box), a move toward the box is allowed
- [ ] Interventions are counted correctly when several rules fire

## Friday 2/10 — `ReachEnv` (≈ 4 h)

File: `reachy_sim/envs/reach_env.py`, registered as `ReachyReach-v0`.

| Part | Spec |
|---|---|
| Action | `Box(-1, 1, (7,))` → `target = q_cmd + a × 5°` → shield → `send_joint_targets`. Build from the last **commanded** target `q_cmd`, not the measured angle, or the arm sags under gravity. |
| Observation (Dict) | `observation` (24): q (7), q̇ (7), hand pos (3), prev action (7) · `achieved_goal` (3): hand pos · `desired_goal` (3): goal pos |
| Goal | random arm pose → hand position, kept if inside the workspace box, so every goal is reachable. Shown with the green marker. The episode starts from home, below the box, so the policy must learn to lift the arm into it. |
| Reset | arm to home + small noise (±3°, clipped to joint limits), settle, sample a goal |
| Reward (dense) | `−d − 0.01‖a‖² − 0.01‖a − a_prev‖² − 0.1 × interventions`, where `d = ‖hand − goal‖` |
| Reward (sparse, for HER) | `0` if `d < 0.03`, else `−1`; implement `compute_reward(achieved, desired, info)` |
| Success | `d < 0.03 m` → `info["is_success"] = True` |
| Episode | 100 steps (5 s at 20 Hz); `truncated` at 100 |
| Render | `"rgb_array"` (videos); watch with `mjpython` + `launch_passive` |

Tests `tests/test_reach_env.py`:
- [ ] `gymnasium.utils.env_checker.check_env(env)` passes
- [ ] The same seed gives identical observations and rewards over 50 steps
- [ ] Random actions never produce a target outside the joint limits
